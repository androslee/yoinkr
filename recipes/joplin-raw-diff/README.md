# Joplin Raw/Diff binding

Exact Joplin 3.7.21 Linux x86-64 recipe for the same immutable MQTT Explorer package used by VS Code. Six hashes and unique main/renderer hooks gate compatibility. Prepare an extracted pinned runtime, then apply only to a new lab copy. The tested configuration uses Joplin safe mode and native note-editor selection; no plugin is installed.
