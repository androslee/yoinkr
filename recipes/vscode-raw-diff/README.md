# VS Code recipient binding

Milestone 19 reference adapter: Microsoft VS Code 1.142.0, Linux x86-64, exact six input fingerprints. Supply your own local runtime and the immutable MQTT Explorer package named by the recipe. The source package stays unchanged; the adapter owns all recipient-specific code.

See [recipient guide](../../docs/FEATURE_HOSTS.md) for plan, fresh-copy installation, native editor selection/clipboard/theme commands, isolated profiles, real-app acceptance and rollback. Unsupported versions and changed input bytes are refused. No extension is installed.

Generated application copies, recovered donor packages and private native evidence are excluded from the public project. The recipe itself contains hashes and requirements, not a redistributed application or copied donor UI implementation. Review each input's license before distributing generated artifacts.
